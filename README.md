# Ecommerce_DataAnalysis
An end-to-end exploratory data analysis (EDA) project evaluating e-commerce sales, discounting strategies, and fulfillment efficiency to drive revenue and customer satisfaction. Built with Python, Pandas, and Seaborn.

## Project Structure
- `Ecommerce_DataAnalysis.ipynb` — End-to-end data cleaning, EDA, visualizations
- `requirements.txt` — Python dependencies needed to reproduce the environment.
- `Ecommerce_DataAnalysis.docx` — Complete analytical report with business recommendations and embedded plots.
- `output_images/` — Directory holding generated high-resolution charts.
- `ecommerce_sales_analytics_5000.csv` — Primary dataset (5,000 rows × 12 analytical columns).

## Dataset
  https://www.kaggle.com/datasets/abbas829/ecommerce-sales-dataset

## Technologies Used
- **Python 3.10+**
- **Pandas & NumPy** — Data cleaning, type conversion, and aggregation
- **Matplotlib & Seaborn** — Exploratory data visualization and statistical plots
- **python-docx** — Programmatic Word document generation
